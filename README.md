# Salim Fraj Portfolio

Personal portfolio site for AI-integrated software projects, full-stack applications, and client deployments.

Live site: https://salim-fraj-portfolio.vercel.app

## Featured Work

### ConsultIQ

AI Builder Workbench for governed agentic workflow prototyping. Demonstrates deterministic tools, compliance gates, human review boundaries, eval coverage, audit traces, and a Capability Candidate Packet for stakeholder handoff.

Live prototype: https://consultiq.vercel.app

### DinnerHelp

Production LLM-integrated PWA for meal planning, pantry management, and recipe discovery. Built with React, TypeScript, Firebase, Zustand, and Groq-powered AI features.

### Smart Restaurant

Full-stack restaurant management system with React, Node.js, Express, authentication, dashboards, real-time communication patterns, AI integration, validation, and backend security middleware.

### Tiffany Bleu Beauty Lounge

Production website and business infrastructure for a real salon, including Next.js, Sanity CMS, structured SEO, accessibility, analytics, email/DNS setup, and security headers.
